# План капкан ♛

Персональная страница приглашения: анимация вопроса, выбор занятий, своё место,
способ передвижения и отправка выбранного плана.

## Публикация в Streamlit Community Cloud

1. Загрузите содержимое этой папки в репозиторий GitHub.
   Файл `app.py` должен лежать в корне репозитория рядом с `requirements.txt`.
   Папка `frontend` должна сохранить свою структуру, включая `assets`.
2. Откройте https://share.streamlit.io/ и нажмите **Create app → Deploy now**
   для приложения из GitHub.
3. Выберите репозиторий, ветку `main` и файл `app.py`.
4. В **App URL / Custom subdomain** укажите `plan-kapkan`, если имя свободно.
5. Нажмите **Deploy**. Для доступа по ссылке проверьте в настройках приложения
   **Sharing**, что его могут открывать все посетители.

Публикация архива ZIP целиком в GitHub не распаковывает проект: загрузите файлы
из распакованного архива. Для личных фотографий можно использовать закрытый
репозиторий и предоставить Streamlit доступ к нему.

## Локальный запуск

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

Все изображения находятся в проекте. Внешние ключи API, база данных и платный
хостинг не нужны. Код не делает бронь и не отправляет сообщения автоматически.

## Проверка после публикации

- «Нет» перемещается, «Да» открывает следующую сцену.
- Выбранные места и собственный вариант можно расположить по порядку.
- «Отправить свой выбор» передаёт текст, транспорт и ссылку на этот же Streamlit-сайт.
- Открытие отправленной ссылки восстанавливает выбор и транспорт.
- Если браузер блокирует меню отправки или буфер обмена внутри компонента,
  появляется поле, из которого можно скопировать сообщение вручную.

Интерфейс работает в прокручиваемом компоненте Streamlit. Перед отправкой
приглашения проверьте его на своём телефоне после публикации.
